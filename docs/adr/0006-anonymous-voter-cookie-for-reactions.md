# Reactions are tied to an anonymous Voter cookie

The guestbook has no accounts, but a Reaction must be cancellable only by the visitor who made it. So the first time a browser reacts, the server gives it a random UUID in an httpOnly `voter_id` cookie (SameSite=Lax, one year), and stores one row per (Entry, Voter) holding `like` or `dislike`. Pressing the same kind again removes the row, and pressing the other kind switches it. We rejected IP addresses (shared behind NAT and mobile networks, so one person could cancel another's vote) and a localStorage id (readable and forgeable by page scripts, and it would have to travel in every request body). Clearing cookies or switching browsers makes a new Voter, which is accepted for a guestbook without login. Reactions are deleted with their Entry.
